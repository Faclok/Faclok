

Большинство проектов осложняются там, где этого не требуется.
Людям нужен результат, но процесс тонет в обсуждениях инструментов и попытках согласовать каждую мелочь.

Если задача должна работать — достаточно чётко описать, **что именно должно происходить**.
Дальше путь прямой:

1. цель зафиксирована;
2. работа выполнена;
3. продукт запущен.
